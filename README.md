# Deutsch A2

Curso de alemán hasta el nivel A2 (Goethe-Zertifikat A2), con explicaciones en español.
Se instala como app en el móvil y funciona sin internet.

**Abrir e instalar:** https://neverdevelopment.github.io/deutsch-a2/

En Chrome (Android/Samsung): toca «Instalar» en la app, o en el menú ⋮ → «Instalar aplicación».
El progreso se guarda en el propio teléfono.
